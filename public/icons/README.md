# Neon Formatted Tech Icons

Place your neon-formatted SVG icons for each technology in this folder.
Rename your icons to match the following filenames, then the site will load them automatically:

- js.svg
- ts.svg
- react.svg
- nextjs.svg
- html5.svg
- css3.svg
- tailwind.svg
- nodejs.svg
- express.svg
- mongodb.svg
- postgresql.svg
- mysql.svg
- git.svg
- github.svg
